# Archive

This directory holds historical, one-off documents from earlier work: task/fix reports, audits,
test-run logs, review plans and similar snapshots.

They are kept for traceability only. Their file paths, test counts, feature status and "missing"
lists may be outdated, and they are **not** a description of the current system. In particular,
reports from before the admin console and VNPay work still describe those features as absent.

Current documentation lives in:

- [`../../README.md`](../../README.md) — project overview and quick start
- [`../feature-list.md`](../feature-list.md) — feature inventory
- [`../api-spec.md`](../api-spec.md) — API contract
- [`../admin-gap-checklist.md`](../admin-gap-checklist.md) — admin work tracker
